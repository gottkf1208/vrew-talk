총 40분. 영상 재생과 짧은 응답 시간을 포함합니다. 영상은 각 장에 적은 구간만 발췌해서 보고, 전체 감상은 강의 뒤 링크로 안내합니다. 정해진 실시간 시작 시각 대신 경과 시간으로 운영합니다.

강의의 중심 문장

“AI에게 눈과 귀가 없다”는 비유를 “AI에게는 우리 반을 아는 눈과 귀가 없다”로 풀어 설명합니다. 영상·음성을 분석하는 AI의 존재를 인정하면서도, 오류 검출과 교육적 판단이 보장되지 않는다는 점을 강조합니다. 브루는 생성 결과를 직접 보고 듣고 수정하는 최종 편집 공간으로 소개합니다.

진행 준비

  • AI 개념극장 두 작품의 도입만 각 20–30초, 기존 소리 비교 영상은 A·B 각 10초 사용합니다. YouTube 광고나 재생 문제가 생기면 슬라이드 질문으로 바로 이어갑니다.
  • 모션랩은 예시 화면을 보고, 90초 동안 내 수업을 여는 질문으로 문구를 바꾸어 짝에게 보여 줍니다. 내보내기는 이후 실습으로 넘깁니다.
  • 소리 비교 영상은 2026년 9월 기존 강의안의 제작 자료이며, 이번 개정에서 새로 만든 영상이 아닙니다. 학습 내용과 비유의 한계는 교과 자료로 다시 확인해 주세요.
  • 브루 시연에서는 영상 자막 수정과 음성 재생성을 구분합니다. 원본 녹음의 잘못된 발음은 자막 수정만으로 바뀌지 않습니다.
  • 시간이 밀리면 작품 전체 감상·공모전 상세 설명·모션랩 라이브 시연을 줄이고, 마지막 13분의 최종 편집 메시지를 확보합니다.
