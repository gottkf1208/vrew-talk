# 브루 연수 전 40분 특강 · 웹 강의안

2026년 10월 24일(토) 티셀파 워크숍(가산디지털단지 천재교육)에서 브루 연수 전에 진행하는 특강 자료예요. AI 영상 제작의 교육적 효과를 미디어교육과 연결하고, 티셀파 자료로 「나의 첫 AI 영상 설계도」를 쓰는 데까지 19장으로 구성했어요.

- 강의안: https://gottkf1208.github.io/vrew-talk/

## 발표할 때

| 키 | 기능 |
|---|---|
| → · Space | 다음 |
| ← | 이전 |
| 1 ~ 5 | 에피소드 이동 |
| T | 설계 타이머(6분 + 4분 + 4분) |
| N | 발표자 대본, 계획 시각, 경과 시간 |
| M | 목차 |
| E | 편집 모드 |
| B | 배경음악 |
| F | 전체화면 |

휴대폰을 세로로 들면 장면이 위아래로 이어지는 읽기 모드로 바뀌어요.

## 내용 고치기

1. E 키를 누르고 점선으로 표시된 글자를 바로 고쳐요.
2. **깃허브에 저장**을 누르고, 처음 한 번은 토큰을 넣어요.
   - https://github.com/settings/personal-access-tokens/new 에서 `vrew-talk` 저장소만 고르고 Contents를 Read and write로 바꿔 만들어요.
3. 수정 내용은 `edits.json`에 저장되고, 1~2분 뒤 새로고침하면 모두에게 반영돼요.

## 밝혀 둘 것

- 서비스 화면은 2026년 9월 25일에 캡처했어요.
- 예시 영상 5편은 모두 Kling 3.0으로 만든 AI 생성 영상이고, 배경음악은 브라우저에서 합성하는 자체 음원이에요.
